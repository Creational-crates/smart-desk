                EXPERIMENTAL FDM
                
                
                Slice for a test print
                
                
                Creates generic single-nozzle G-code from closed meshes. Review every setting and the output before use.
                
            
                
            
                
                Not a production-slicer replacement: one boundary pass only; no perimeter offsets, supports, retraction, bridging,
                travel optimization, material-specific validation, printer-specific start code, or print-time estimate. Bodies are sliced
                separately; overlapping shells are not unioned and may print twice. There is no skirt/brim. Boolean-union
                overlapping parts first.
                Validate the file in your printer’s own slicer/host and supervise the first layer.
